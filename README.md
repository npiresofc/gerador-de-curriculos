# Gerador de Currículos

## Sobre o projeto

O Gerador de Currículos é um projeto pessoal desenvolvido com HTML, CSS e JavaScript, com o objetivo de permitir a criação de currículos de maneira simples e prática diretamente pelo navegador.

O usuário preenche suas informações profissionais em um formulário e acompanha a atualização automática de uma prévia do currículo, podendo imprimir ou salvar o resultado em PDF.

O projeto foi desenvolvido para praticar conceitos básicos de desenvolvimento web, principalmente a manipulação do DOM e a interação com formulários utilizando JavaScript.

![Tela principal do Gerador de Currículos](images/telaprincipal.png)


## Funcionalidades

- Preenchimento de informações pessoais e profissionais.
- Visualização do currículo atualizada em tempo real.
- Opção para limpar os campos preenchidos.
- Impressão ou salvamento do currículo em PDF pelo navegador.

## Tecnologias utilizadas

- **HTML5:** estrutura da página e dos formulários.
- **CSS3:** estilização do site e formatação para impressão.
- **JavaScript:** manipulação do DOM e atualização dinâmica das informações.

## Como executar

Baixe os arquivos do repositório e abra o `index.html` no navegador. Não é necessário instalar dependências ou configurar um servidor.

Também é possível utilizar a demonstração online após a publicação pelo GitHub Pages.

## Demonstração online

## Ressalvas finais

Este é um projeto pessoal de aprendizado, desenvolvido com foco na utilização de conceitos básicos de HTML, CSS e JavaScript.

Durante o desenvolvimento, utilizei Inteligência Artificial como apoio em partes da estilização CSS para otimizar o tempo, mantendo as soluções dentro dos conhecimentos que possuo sobre a linguagem.

A geração do PDF utiliza a função de impressão do próprio navegador, sem bibliotecas externas.
